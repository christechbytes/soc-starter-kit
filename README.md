# SOC Starter Kit

**What I wish I knew as a career changer breaking into cybersecurity.**

## About me

I'm Christine, a Cybersecurity analyst based in Barbados. I spent 13 years in another career before moving into cybersecurity through a certificate program and an internship. I built this repo for people who are where I was not long ago: curious, motivated, and unsure where to start.

**Certifications:** CompTIA Security+ (2025), CompTIA Network+ (2026), Microsoft Azure Fundamentals AZ-900 (2026)

## Who this is for

- Career changers moving into security
- Students and new SOC analysts
- Anyone who wants practical examples instead of theory

## What's inside

| Section | What you'll find |
|---|---|
| [00 Start Here](00-start-here/) | What signals are, why they trigger, and how to investigate using the 5 W's |
| [01 Runbooks](01-runbooks/) | Step by step triage guides for AWS GuardDuty findings and Microsoft Entra ID sign in alerts |
| [02 Change Management](02-change-management/) | Blank change log and change request templates, plus why auditors care |
| [03 Firewall Alerts for SOC Analysts](03-firewall-alerts/) | What firewall logs tell you and how to triage common firewall alerts |
| [04 Troubleshooting](04-troubleshooting/) | A real world style lesson: what to do when security alerts stop arriving |
| [05 Career Path](05-career-path/) | My certification order, study tips, and what the job looks like day to day |
| [06 Entra ID Sign Ins](06-entra-id/) | How to read Microsoft Entra ID sign in events and common error codes |


## Important note

All examples use fictional companies, IP addresses, and account IDs. Nothing here comes from a real organization's environment.
